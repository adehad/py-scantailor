4. Select Content
#################

.. screenshot:: stage4_select_content
   :alt: Select Content with its Page Box and Content Box panels

Finds the area of the page that holds text and pictures. **Content Box** is
**Disable**, **Auto** or **Manual**; in manual mode drag the box edges in the image.
**Page Box** does the same for the page boundary. **Apply to ...** copies the
setting to other pages.
