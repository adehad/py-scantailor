Batch processing
################

.. screenshot:: batch_progress
   :alt: The Batch processing window after four pages were written

Press the play button next to a stage in the stage list to process the current page
and the pages after it through all stages. The **Batch processing** window shows a
progress bar and one line per finished page. **Stop** stops new pages from starting;
pages already running finish.

While a batch runs, the stage list and options are locked.
